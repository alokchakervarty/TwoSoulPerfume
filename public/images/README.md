# Image Assets

Place storefront images here so React can reference them with public URLs.

## Folders

- `brand/` - logo, hero banners, brand campaign images
- `products/` - product bottle images and product gallery photos

## Example URLs

- `public/images/brand/logo.png` becomes `/images/brand/logo.png`
- `public/images/products/after-hour.jpg` becomes `/images/products/after-hour.jpg`

For product API data, add these public URLs in CommerceCore as `imageUrls`, for example:

```json
[
  "/images/products/after-hour.jpg"
]
```
